# 协议

从站地址 `1`。仿真不绑死波特率；移植到 UART 时用 115200 8N1。

## 库位

列 `A`–`D`，行 `1`–`6`。`A3` 这种名字只在 JSON 里出现。Modbus 用从 0 开始的下标：

```
index = (行 - 1) * 4 + (列 - 'A')
```

`A1` 是 0，`B1` 是 1，`A3` 是 8，`D6` 是 23。

坐标（毫米）：

| 点 | X | Y | Z |
| --- | --- | --- | --- |
| 库位 | 40 + 列 × 120 | 30 + (行-1) × 80 | 取放 150，安全 0 |
| 出库口 | 20 | 520 | 取放 140，安全 0 |

软限位：X 0–500 mm，Y 0–600 mm，Z 0–180 mm。Z = 0 在上方，向下为正。

## MQTT

| 主题 | 方向 | 内容 |
| --- | --- | --- |
| `sss/task` | 控制器发布 | 前端任务列表和底栏 |
| `sss/cell/cmd` | 控制器订阅 | 下面的命令 |
| `sss/cell/status` | 控制器发布 | 坐标、夹爪、故障，约 10 Hz |

`sss/task` 的 `groupState` 只有 `RUN`、`PAUSE`、`FINISH`。急停、空抓、看门狗也发 `PAUSE`，原因写在 `poolInfo`。

### 命令

```json
{"cmd":"storage_out","groupId":"G1001","slot":"A3","speed":100}
{"cmd":"storage_in","groupId":"G1002","slot":"A3","speed":80}
{"cmd":"home","groupId":"H1"}
{"cmd":"pause"}
{"cmd":"resume"}
{"cmd":"stop"}
{"cmd":"reset"}
{"cmd":"speed","speed":60}
```

`groupId`、`slot`、`speed` 可以缺省。缺省的任务号会编成 `MB1`、`MB2`。`speed` 是 1–100，按百分比缩放三轴最大速度。

返回码（`cell_cmd` / `cell_cmd_json`）：

| 值 | 含义 |
| --- | --- |
| 0 | 已接受 |
| -1 | 字段或库位名不合法 |
| -2 | 正在跑别的任务 |
| -3 | 急停、门、故障，或库位/出库口的物料状态不对 |

出库要求库位有料且出库口是空的。入库相反。空抓不会把库存改掉。

## Modbus 保持寄存器

功能码 `03` 读，`06` 写单个，`16` 写多个。异常码 `01` 功能不支持，`02` 地址非法，`03` 值非法。CRC 错或站号不对时从站不回答。

| 地址 | 名称 | 访问 | 说明 |
| --- | --- | --- | --- |
| 0 | STATUS | R | 见下表 |
| 1 | FAULT | R | 0 无，1 急停，2 门，3 软限位，4 空抓，5 看门狗，6 库位，7 脱落 |
| 2 | JOB | R | 0 空闲，1 回零，2 出库，3 入库，4 停车 |
| 3 | SPEED | R | 当前速度百分比 |
| 4–5 | X | R | 位置，微米，int32，高字在前 |
| 6–7 | Y | R | 同上 |
| 8–9 | Z | R | 同上 |
| 10 | CMD | W | 写一次触发，读回总是 0 |
| 11 | SLOT | R/W | 库位下标 0–23 |
| 12 | SPEED_ARG | R/W | 1–100，配合命令 8 |
| 13 | STEP | R | 当前步序号 |
| 14 | HOLDING | R | 夹爪里有没有料 |
| 15 | HEARTBEAT | R | 每 100 ms 加一 |

STATUS 位：0 已回零，1 忙，2 故障，3 暂停，4 夹爪闭合，5 夹着料，6 门关好，7 急停锁存。

CMD：1 回零，2 出库，3 入库，4 暂停，5 继续，6 停止，7 复位，8 把 SPEED_ARG 写成速度。先写 11 和 12，再写 10。

看门狗 500 ms。通信任务每个周期调用 `cell_kick`，超时后故障码 5，轴按急停减速停下。
